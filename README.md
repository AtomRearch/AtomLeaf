AtomLeaf 是 AtomRearch 正在开发的图像与笔记产品：接住零散的图、原话和想法，让它们经过自己的思考与确认，成为愿意再次翻开的一页。

## 留下 → 理解 → 再次遇见

- **先留下**：图片、片段与随想不必先整理好；阅读、生活、艺术、旅行、实验都可以成为起点。
- **一起想**：AI 围绕选中的材料整理、追问与练习；原稿和候选分开，由你确认留下什么。
- **再翻开**：图卡、书架、标签、检索与可导出的资料，连接记录和重温。

## 当前进展

Android 0.12.0 处于私人测试，已有首批图文模型流程与桌面组件。iOS 源码待 Mac 构建和设备验收；Windows 独立桌面版、自动语音转写及自动同步仍在开发规划中。尚未开放公开下载、注册或订阅。

官网的七组案例及整理输出均为原创、预写演示，交互体验只存在当前页面内存；不会发送模型请求，不读取或保存 App 资料。
